Examples
========

A gallery of compact, runnable examples that explain the calculations behind
RosettaX workflows. Each example uses the implementation that the application
uses, with deliberately small synthetic calibration tables so that every point
and fit parameter is easy to inspect.

The examples are teaching aids, not substitute calibration records. Create and
save real calibrations in the local RosettaX application using the appropriate
FCS data, detector settings, and reference material.
